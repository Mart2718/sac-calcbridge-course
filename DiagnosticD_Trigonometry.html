How to use this page

If $\sin x = \tfrac{1}{3}$ and $\sec y = \tfrac{5}{4}$, where $x$ and $y$ lie between $0$ and $\tfrac{\pi}{2}$, evaluate $\sin(x+y)$.
0/1 rated
▾
(a)
$\sin(x+y) = ?$
Answer
$\dfrac{4+6\sqrt{2}}{15}$
$\cos x = \dfrac{2\sqrt{2}}{3}$, $\cos y = \dfrac{4}{5}$, $\sin y = \dfrac{3}{5}$. Then $\sin(x+y) = \sin x\cos y + \cos x\sin y = \dfrac{1}{3}\cdot\dfrac{4}{5} + \dfrac{2\sqrt{2}}{3}\cdot\dfrac{3}{5}$
7
Prove each identity.
0/2 rated
▾
(a)
$\tan\theta\sin\theta + \cos\theta = \sec\theta$
Answer
$\tan\theta\sin\theta + \cos\theta = \dfrac{\sin^2\theta}{\cos\theta} + \dfrac{\cos^2\theta}{\cos\theta} = \dfrac{1}{\cos\theta} = \sec\theta$
Start from the left side and combine over a common denominator  ($\cos\theta \neq 0$)
(b)
$\dfrac{2\tan x}{1+\tan^2 x} = \sin 2x$
Answer
$\dfrac{2\sin x/\cos x}{\sec^2 x} = 2\sin x\cos x = \sin 2x$
Use $1+\tan^2 x = \sec^2 x$ and simplify
8
Find all values of $x$ such that $\sin 2x = \sin x$ and $0 \leq x \leq 2\pi$.
0/1 rated
▾
(a)
$x = ?$
Answer
$x = 0,\;\dfrac{\pi}{3},\;\pi,\;\dfrac{5\pi}{3},\;2\pi$
$2\sin x\cos x - \sin x = 0 \Rightarrow \sin x(2\cos x - 1) = 0$. So $\sin x = 0$ or $\cos x = \frac{1}{2}$

0/1 rated

(a)

Answer
$\text{Period } \pi,\;\text{amplitude }1,\;\text{shifted up 1 unit}$
Start with $y = \sin x$: compress horizontally by factor 2 (period $\pi$), then shift up 1. Range: $[0, 2]$. Key points: $(0,1)$, $(\pi/4,2)$, $(\pi/2,1)$, $(3\pi/4,0)$, $(\pi,1)$

S6
Sum-Difference Identity
0/1 rated
▾
(a)
Given $\cos x = \dfrac{4}{5}$ and $\sin y = \dfrac{5}{13}$ (both in Q1), evaluate $\cos(x - y)$.
Answer
$\dfrac{63}{65}$
$\sin x = \frac{3}{5}$, $\cos y = \frac{12}{13}$. $\cos(x-y) = \cos x\cos y + \sin x\sin y = \frac{4}{5}\cdot\frac{12}{13} + \frac{3}{5}\cdot\frac{5}{13} = \frac{48}{65} + \frac{15}{65} = \frac{63}{65}$
S7
Prove the Identity
0/1 rated
▾
(a)
Prove: $\sec^2\theta - 1 = \tan^2\theta$
Answer
\sec^2\theta - 1 = (\tan^2\theta + 1) - 1 = \tan^2\theta \quad \checkmark
Start with the Pythagorean identity $\tan^2\theta + 1 = \sec^2\theta$, then subtract 1 from both sides  ($\cos\theta \neq 0$).
S8
Solving Trig Equations
0/1 rated
▾
(a)
Solve $\cos 2x = \cos x$ for $0 \leq x \leq 2\pi$.
Answer
$x = 0,\; \dfrac{2\pi}{3},\; \dfrac{4\pi}{3},\; 2\pi$
Use $\cos 2x = 2\cos^2 x - 1$: $2\cos^2 x - \cos x - 1 = 0 \Rightarrow (2\cos x + 1)(\cos x - 1) = 0$. So $\cos x = 1$ or $\cos x = -\frac{1}{2}$.

Graphing

(a)
Sketch $y = 2\cos\!\left(x - \dfrac{\pi}{2}\right)$ without a calculator.
Answer
\text{Amplitude } 2,\; \text{period } 2\pi,\; \text{phase shift } \tfrac{\pi}{2} \text{ right}
Equivalently $y = 2\sin x$ (since $\cos(x - \frac{\pi}{2}) = \sin x$). Key points: $(0,0)$, $(\frac{\pi}{2}, 2)$, $(\pi, 0)$, $(\frac{3\pi}{2}, -2)$, $(2\pi, 0)$.

▾
(a)
$\dfrac{x^2+3x+2}{x^2-x-2}$
Answer
$\dfrac{x+2}{x-2}$
Factor: $\dfrac{(x+1)(x+2)}{(x+1)(x-2)} = \dfrac{x+2}{x-2}$  ($x \neq -1,\; x \neq 2$)
(b)
$\dfrac{2x^2-x-1}{x^2-9} \cdot \dfrac{x+3}{2x+1}$
Answer
$\dfrac{x-1}{x-3}$
Factor: $\dfrac{(2x+1)(x-1)}{(x+3)(x-3)} \cdot \dfrac{x+3}{2x+1} = \dfrac{x-1}{x-3}$  ($x \neq \pm 3,\; x \neq -\tfrac{1}{2}$)
(c)
$\dfrac{x^2}{x^2-4} - \dfrac{x+1}{x+2}$
Answer
$\dfrac{1}{x-2}$
Common denominator $(x+2)(x-2)$: $\dfrac{x^2-(x+1)(x-2)}{(x^2-4)} = \dfrac{x+2}{(x+2)(x-2)} = \dfrac{1}{x-2}$  ($x \neq \pm 2$)
(d)
$\dfrac{\dfrac{y}{x} - \dfrac{x}{y}}{\dfrac{1}{y} - \dfrac{1}{x}}$
Answer
$-(x+y)$
Multiply numerator and denominator by $xy$: $\dfrac{y^2-x^2}{x-y} = \dfrac{(y-x)(y+x)}{x-y} = -(x+y)$  ($x \neq 0,\; y \neq 0,\; x \neq y$)

Solve the equation. (Find only the real solutions.)
0/7 rated
▾
(a)
$x + 5 = 14 - \tfrac{1}{2}x$
Answer
$x = 6$
(b)
$\dfrac{2x}{x+1} = 2x - 1$
Answer
$x = -\dfrac{1}{2} \text{ or } x = 1$
Multiply both sides by $(x+1)$, $x\neq -1$: $2x = (2x-1)(x+1) = 2x^2+x-1$. Rearrange: $2x^2-x-1=0$, factor $(2x+1)(x-1)=0$. Both solutions satisfy the original equation.
(c)
$x^2 - x - 12 = 0$
Answer
$x = -3 \text{ or } x = 4$
Factor: $(x+3)(x-4) = 0$
(d)
$2x^2 + 4x + 1 = 0$
Answer
$x = -1 \pm \dfrac{\sqrt{2}}{2}$
Quadratic formula: $x = \dfrac{-4 \pm \sqrt{16-8}}{4} = \dfrac{-4 \pm 2\sqrt{2}}{4}$
(e)
$x^4 - 3x^2 + 2 = 0$
Answer
$x = \pm 1 \text{ or } x = \pm\sqrt{2}$
Let $u = x^2$: $(u-1)(u-2) = 0$
(f)
$3|x-4| = 10$
Answer
$x = \dfrac{2}{3} \text{ or } x = \dfrac{22}{3}$
(g)
$2x(4-x)^{-1/2} - 3\sqrt{4-x} = 0$
Answer
$x = \dfrac{12}{5}$
Multiply through by $(4-x)^{1/2}$: $2x - 3(4-x) = 0 \Rightarrow 5x = 12$

Solve each inequality. Write your answer using interval notation.
0/5 rated
▾
(a)
$-4 \leq 5 - 3x \leq 17$
Answer
$[-4, 3)$
Subtract 5: $-9 \leq -3x \leq 12$, divide by $-3$ (flip inequalities): $-4 \leq x < 3$
(b)
$x^2 < 2x + 8$
Answer
$(-2, 4)$
$x^2 - 2x - 8 < 0$, factor $(x+2)(x-4) < 0$
(c)
$x(x-1)(x+2) > 0$
Answer
$(-2, 0) \cup (1, \infty)$
Sign chart with critical values $x = -2, 0, 1$
(d)
$|x - 4| < 3$
Answer
$(1, 7)$
$-3 < x-4 < 3 \Rightarrow 1 < x < 7$
(e)
$\dfrac{2x-3}{x+1} \geq 1$
Answer
$(-\infty, -1) \cup [4, \infty)$
$\dfrac{2x-3}{x+1} - 1 \geq 0 \Rightarrow \dfrac{x-4}{x+1} \geq 0$. Sign chart with critical values $x=-1$ (excluded) and $x=4$ (included): expression is $\geq 0$ when both factors share the same sign.
10
State whether each equation is true or false for every input where both sides are defined.
0/6 rated
▾
(a)
$(p+q)^2 = p^2 + q^2$
Answer
$\textbf{False}$
$(p+q)^2 = p^2 + 2pq + q^2 \neq p^2+q^2$ in general (e.g. $p=q=1$: LHS $= 4$, RHS $= 2$)
(b)
$\sqrt{ab} = \sqrt{a} \cdot \sqrt{b} \quad (a,\, b \geq 0)$
Answer
$\textbf{True}$
$\sqrt{ab} = (ab)^{1/2} = a^{1/2}b^{1/2} = \sqrt{a}\,\sqrt{b}$
(c)
$\sqrt{a^2+b^2} = a + b$
Answer
$\textbf{False}$
Try $a=b=1$: $\sqrt{2} \neq 2$
(d)
$\dfrac{1+TC}{C} = 1 + T$
Answer
$\textbf{False}$
$\dfrac{1+TC}{C} = \dfrac{1}{C} + T \neq 1 + T$
(e)
$\dfrac{1}{x+y} = \dfrac{1}{x} + \dfrac{1}{y}$
Answer
$\textbf{False}$
Try $x=y=1$: LHS $= \frac{1}{2}$, RHS $= 2$
(f)
$\dfrac{1/x}{a/x - b/x} = \dfrac{1}{a-b}$
Answer
$\textbf{True}$
$\dfrac{1/x}{(a-b)/x} = \dfrac{1}{a-b}$ (for $x \neq 0, a \neq b$)

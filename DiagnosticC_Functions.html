How to use this page

Functions are the central objects of calculus. Make sure you can read graphs, find domains, describe transformations, and evaluate compositions — these skills appear daily in Calc 1.

The graph of a function $f$ is given. Answer parts (a)–(e).

Use the graph of $f$ below for all parts of this question.
(a)
State the value of $f(-1)$.
Answer
$f(-1) = -2$
Locate $x = -1$ on the $x$-axis and read the $y$-coordinate of the curve.
(b)
Estimate the value of $f(2)$.
Answer
$f(2) \approx 2.8$
Locate $x = 2$ and estimate the height of the curve above the $x$-axis.
(c)
For what values of $x$ is $f(x) = 2$?
Answer
$x = -3$ and $x = 1$
Find where the curve intersects the horizontal line $y = 2$ (the teal dots on that level).
(d)
Estimate the values of $x$ such that $f(x) = 0$.
Answer
$x \approx -2.5$ and $x \approx 0.3$
Find where the curve crosses the $x$-axis.
(e)
State the domain and range of $f$.
Answer
Domain $= [-3,\,3]$,   Range $= [-2,\,3]$
Domain: the full set of $x$-values shown. Range: the full set of $y$-values the curve reaches.
2
If $f(x) = x^3$, evaluate the difference quotient $\dfrac{f(2+h)-f(2)}{h}$ and simplify your answer.
0/1 rated
▾
(a)
$\dfrac{f(2+h)-f(2)}{h}$
Answer
$12 + 6h + h^2$
$(2+h)^3 = 8+12h+6h^2+h^3$; subtract $8$; divide by $h$: $12+6h+h^2$  ($h \neq 0$)
3
Find the domain of each function.
0/3 rated
▾
(a)
$f(x) = \dfrac{2x+1}{x^2+x-2}$
Answer
$(-\infty,-2)\cup(-2,1)\cup(1,\infty)$
Set $x^2+x-2 = (x-1)(x+2) = 0$: exclude $x=1$ and $x=-2$
(b)
$g(x) = \dfrac{\sqrt[3]{x}}{x^2+1}$
Answer
$(-\infty,\infty)$
Cube root is defined everywhere; denominator $x^2+1 \geq 1 > 0$ always
(c)
$h(x) = \sqrt{4-x} + \sqrt{x^2-1}$
Answer
$(-\infty,-1]\cup[1,4]$
Need $4-x \geq 0$ (so $x \leq 4$) AND $x^2-1 \geq 0$ (so $|x| \geq 1$)

6
Let $f(x) = \begin{cases} 1-x^2 & x \leq 0 \\ 2x+1 & x > 0 \end{cases}$
0/2 rated
▾
(a)
$\text{Evaluate } f(-2) \text{ and } f(1)$
Answer
$f(-2) = -3,\quad f(1) = 3$
$f(-2) = 1-(-2)^2 = 1-4 = -3$; $\;f(1) = 2(1)+1 = 3$
(b)
$\text{Sketch the graph of } f$
Answer
$\text{Left piece: downward parabola } y=1-x^2 \text{ for }x\leq 0;\;\text{right piece: line }y=2x+1\text{ for }x>0$
The pieces connect at $(0,1)$: left piece supplies the actual value $f(0)=1$ (filled point), right piece approaches $1$ from above (open circle). Draw a filled point at $(0,1)$.
7
If $f(x) = x^2+2x-1$ and $g(x) = 2x-3$, find:
0/3 rated
▾
(a)
$(f \circ g)(x)$
Answer
$4x^2 - 8x + 2$
$f(g(x)) = f(2x-3) = (2x-3)^2 + 2(2x-3)-1 = 4x^2-12x+9+4x-6-1$
(b)
$(g \circ f)(x)$
Answer
$2x^2 + 4x - 5$
$g(f(x)) = 2(x^2+2x-1)-3 = 2x^2+4x-2-3$
(c)
$(g \circ g \circ g)(x)$
Answer
$8x - 21$
$g(g(x)) = 2(2x-3)-3 = 4x-9$; then $g(4x-9) = 2(4x-9)-3 = 8x-21$

S1
Graphing
0/1 rated
▾
(a)
Let $f$ be a linear function that passes through $(-2,\,3)$, $(0,\,1)$, and $(2,\,-1)$. Find $f(0)$ and the interval where $f(x) > 0$.
Answer
$f(0) = 1$;   $f(x) > 0$ on $(-\infty,\,1)$
The three points are collinear with slope $-1$, giving $f(x) = -x+1$. So $f(x) > 0$ when $-x+1 > 0$, i.e. $x < 1$.
S2
Difference Quotient
0/1 rated
▾
(a)
If $f(x) = x^2 - 3x$, evaluate $\dfrac{f(1+h) - f(1)}{h}$.
Answer
$h - 1$
$f(1+h) = (1+h)^2-3(1+h) = h^2-h-2$; $\;f(1)=-2$. So $\dfrac{h^2-h}{h} = h-1$  ($h \neq 0$).

(a)
Find the domain of $g(x) = \dfrac{1}{\sqrt{4-x}}$.
Answer
$(-\infty,\,4)$
Need $4 - x > 0$ (strict — denominator can't be zero), so $x < 4$.
S4
Transformations
0/1 rated
▾
(a)
Describe the transformations applied to $f(x)$ to obtain $h(x) = -2f(x+1)$.
Answer
\text{Shift left 1 unit, vertical stretch by factor 2, reflect over the } x\text{-axis}
Reading inside-out: $(x+1)$ shifts left 1; multiply by 2 stretches vertically; the negative sign reflects over the $x$-axis.
S5
Graph Sketching
0/1 rated
▾
(a)
Sketch $g(x) = -(x+1)^2 + 3$.
Answer
\text{Downward-opening parabola, vertex at } (-1,\,3)
Vertex form: vertex $(-1, 3)$, opens down (negative leading coefficient). $x$-intercepts where $(x+1)^2 = 3$, i.e. $x = -1 \pm \sqrt{3}$.
S6
Piecewise Functions
0/1 rated
▾
(a)
Let $f(x) = \begin{cases} x+2 & x < 0 \\ 4-x^2 & x \geq 0 \end{cases}$. Find $f(-3)$ and $f(2)$.
Answer
$f(-3) = -1$;   $f(2) = 0$
$f(-3)$: use $x+2$ since $-3 < 0$ → $-3+2 = -1$. $f(2)$: use $4-x^2$ since $2 \geq 0$ → $4-4 = 0$.
S7
Composition
0/1 rated
▾
(a)
Given $f(x) = 3x+2$ and $g(x) = x^2$, find $(g \circ f)(x)$ and $(f \circ g)(1)$.
Answer
$(g \circ f)(x) = (3x+2)^2$;   $(f \circ g)(1) = 5$
$(g \circ f)(x) = g(f(x)) = g(3x+2) = (3x+2)^2$. $(f \circ g)(1) = f(g(1)) = f(1) = 3(1)+2 = 5$.
